# 2021秋季第10讲 丘成桐：近代几何的历史

## 一、数学家的人生经历

### 1. 蒙日（Gaspard Monge，1746-1818）

蒙日出身贫寒，父亲是一个磨刀匠，并非贵族。但他父亲重视教育，使蒙日得以进入地方学院学习。他很早就对几何和工程学产生兴趣，14岁便设计了一辆消防车，16岁绘制了一幅出色的博恩（Beaune）地区地图。他得到一位工程官员的赏识，进入皇家军事工程学院研究筑城学（军事工程的防御工事设计），此后开始研究画法几何（descriptive geometry）。

蒙日的工作主要有两方面：其一是画法几何——用两个正交投影面来研究立体几何，系统化地用微积分处理相关问题，对当时军事工程和机械设计有重要实用价值（尽管今天已被计算机取代）。其二是**最优传输问题（optimal transport）**——这是蒙日影响后世最深远的贡献。他考虑了如何以最小成本搬运土方的问题（后世抽象为概率分布的传输），这一问题在后来 Kantorovich/Brenier 的二次成本框架下导出著名的**蒙日-安培方程（Monge-Ampère equation）**，该方程在20世纪几何学中反复出现，涉及闵可夫斯基问题、等距嵌入问题等，并在近二三十年被广泛应用于人工智能领域。苏联数学家康托罗维奇（Kantorovich）给出了实际计算方案；他后来因资源最优配置理论（与库普曼斯）获诺贝尔经济学奖。

蒙日曾随拿破仑出征，获得勋章。他带领学生用综合方法研究几何，拉格朗日赞赏他将分析学运用于几何的手法。

### 2. 高斯（Carl Friedrich Gauss，1777-1855）

高斯出生于德国不伦瑞克（Brunswick）一个贫穷家庭，母亲未受过教育，父亲做过园丁和小保险公司评估师，两人都不认为学问有用。但高斯自幼酷爱读书，少年时遇到一位老师及其助手，并得到一位公爵的资助，得以进入不伦瑞克工业大学学习[^fn01001]，18岁转入哥廷根大学。他后来成为哥廷根大学教授兼天文台台长。

**早期成就**：17岁时发现素数分布定律（prime number distribution law）和最小二乘法[^fn01002]；18岁（1796年3月30日）证明了正十七边形可以用尺规作图，此事深刻影响了他对分圆域（cyclotomic field）的研究。

**数论贡献**：证明了二次互反律（reciprocity law），给出了六个不同证明；提出素数分布猜想（后被哈达玛和德拉瓦莱-普桑于1896年证明）；对椭圆函数和超几何函数有深入研究，发现了算术几何平均与椭圆积分之间的深刻联系；首次提出模方程（modular equation）的概念。

**微分几何贡献**：高斯开创性地用参数表示曲面（而非仅用方程 $F=0$），这影响了黎曼几何的发展。他提出了高斯曲率（Gaussian curvature）的概念——两个主曲率 $k_1$ 与 $k_2$ 的乘积——并发现它只与曲面本身的度量有关，与曲面在三维空间中的嵌入方式无关，这是划时代的内蕴几何观念。他定义了高斯映射（Gauss map），将曲面上的法向量平移到单位球面上，由此证明了**高斯-博内定理（Gauss-Bonnet theorem）**的局部形式（测地三角形情形）——整体形式 $\int K\,dA=2\pi\chi$（Bonnet 等）将曲率积分与欧拉示性数联系起来；带边界时需加边界测地曲率项，这一桥梁对20世纪几何与拓扑的关系影响深远。高斯映射的推广——格拉斯曼（Grassmann）流形上的映射——与陈类（Chern class）等特征类的分类空间表述密切相关。

**其他贡献**：证明了代数基本定理（给出多个证明）；研究大地测量时发展了共形映射理论；发现环绕数（linking number）的积分公式；在物理学上有高斯定律（其数学形式与散度定理密切相关；散度定理的早期形式由拉格朗日给出）、与韦伯共同制造了第一台可操作的电报。

高斯生前有大量工作未发表（日记中记载了146个发现）[^fn01003]，他追求完美，只发表他认为完整的作品。他从贫寒出身到成为"数学王子"，全靠自身奋斗。

## 二、演讲的叙述结构和思路变化、整体脉络

本讲是"近代几何的历史"系列第五讲，丘成桐的叙事以**人物列传型**为主，按时间顺序逐一讲述18-19世纪数学家的生平与贡献，但始终以**几何学的演进**为主线进行筛选和串联。

**整体框架**：演讲分为两大部分——蒙日篇与高斯篇。蒙日部分较短（约1/4篇幅），高斯部分为主体（约3/4篇幅）。开篇丘成桐即点明一个关键主题：这些表面上与几何无关的内容（如数论、椭圆函数），实际上与近代几何有着深层的联系，听众需待到20世纪几何部分才能完全理解。

**蒙日部分的叙事逻辑**：丘成桐先勾勒蒙日的贫寒出身与工程背景，引出画法几何，随即点出其真正的历史遗产不在画法几何（已被淘汰），而在最优传输问题。他详细解释了最优传输的数学表述，并由此导出蒙日-安培方程，铺设了一条从18世纪直通20世纪几何学和当代人工智能的线索。这一处理方式展现了**"以问题驱动"**的叙事风格：从一个具体问题出发，展示其跨越两百年的生命力。

**高斯部分的叙事逻辑**：这是演讲的核心，丘成桐采用了**"主题分类型"与时间顺序相结合**的方式。他先讲述高斯的出身和成长（强调自身奋斗、良师与贵人），然后按主题板块展开：尺规作图与十七边形 → 素数分布猜想 → 最小二乘法与正态分布 → 大地测量 → 微分几何（参数表示、高斯曲率、高斯映射、高斯-博内定理） → 环绕数公式 → 非欧几何 → 代数基本定理 → 二次互反律 → 椭圆函数与超几何级数 → 模方程 → 物理贡献。

**关键转折点**：演讲在高斯微分几何部分有一个重要的视角提升——丘成桐从高斯映射的推广引出格拉斯曼流形，进而连接到陈类（Chern class）和20世纪指标定理，将19世纪初的一个"小构造"与两百年后的数学高峰直接挂钩。这一"纵向拉伸"是丘成桐叙事风格的标志：不断在历史叙述中插入现代数学的回响，让听众感受到数学发展的连续性。

**叙事风格**：丘成桐的口吻带有鲜明的个人色彩——粤语口音痕迹（如"告斯"即高斯、"告示"即高斯）、口语化表达（"呵呵""对不对"）、以及大量的"你回家试试看""你可以试试看"等互动式语言。他善于用生活化比喻（橘子运苹果解释最优传输、开巴士vs. 开高铁比喻不同运输方案），也频繁穿插个人经验（如"我第一次看高斯映射觉得没什么东西，过了很久才晓得它的重要性"）。结尾处的问答环节，他强调向大数学家学习、培养对数学的兴奋感（excitement），将历史讲述升华为治学之道的传授。

## 三、演讲原文

今天继续讲近代几何的历史。你可能会觉得奇怪，我讲几何，为什么开始讲一些表面上跟几何无关的历史？事实上，几何与分析分不开，我今天讲的东西都跟近代几何有密切关系——以后讲到20世纪的几何时你就会明白。

我们先讲蒙日（Monge）。他生于1746年，卒于1818年，是法国数学家。18世纪从欧拉以后，数学中心从意大利转到瑞士，再分到法国，出现了拉格朗日、拉普拉斯等一大批法国数学家[^fn01004]。蒙日的父亲是个磨刀匠，出身不是贵族，但父亲重视教育，蒙日得以进地方学院读书。他很早就喜欢几何和工程学，14岁设计了一辆消防车，16岁画了一幅出色的博恩地图。他得到工程官员的赏识，进入皇家军事工程学院研究筑城学——就是军事工程的防御工事设计。他设计的工事没有漏洞，使己方不会暴露在敌方火力下，这需要画法几何的帮忙。

画法几何其实就是工程几何，主要解决机械制图和图解方法问题。蒙日建议用两个正交投影面来研究立体几何——方法虽然简单，但对当时的制图来说是革命性的。他用微积分系统化地研究此类问题，影响了后来高斯的工作，不过影响不算深刻。蒙日随拿破仑出征获得勋章[^fn01005]，他带着学生用综合方法研究几何，拉格朗日赞赏他将分析学运用于几何的手法。

但画法几何今天已基本不用了。蒙日真正影响后世的是最优传输问题（optimal transport）。假设有两堆东西，各有一个概率分布——全部加起来等于一。我们要将一个分布输送到另一个分布，运输有成本。从数学上讲，我们有两个概率分布 $μ$ 和 $μ$\*，各有密度 $f$ 和 $g$。运输成本最简单的取法是距离的平方 $|x-y|^2$[^s30340]。问题是要找到一个映射 T，使得 T 将 $μ$ 推前（push-forward）为 $μ$\*（即概率保持不变），同时最小化总运输成本 $∫ c(x,T(x)) dμ(x)$。这就是最优传输问题。

大约三十年前，布伦纳（Brenier）证明[^fn01006]：在 f、g 可积的条件下，最优传输映射 T 存在且唯一[^fn01007]，而且 T 是一个凸函数 $u$ 的梯度。这导出著名的蒙日-安培方程（Monge-Ampère equation）：$\det(D^2u)$ 的表达式与密度变换有关。这是一个高度非线性的偏微分方程，在20世纪几何学中反复出现——闵可夫斯基问题、等距嵌入问题都归结为此类方程。近二三十年来，这个方程在人工智能领域也有重要应用。苏联数学家康托罗维奇给出了实际计算方案，并因此在经济学上获得诺贝尔奖。

接下来讲高斯（Gauss），很多人认为他是历史上最伟大的数学家。高斯被称为"数学王子"，他的工作实在重要，且从小就有重要贡献。他出生在德国不伦瑞克，家庭贫穷，母亲没受过教育，父亲做过园丁和小保险公司评估师，两人都不认为学问有用。但高斯喜欢看书，父母阻止不了。他遇到一位好老师和一位助手，又幸运地得到一位公爵的资助——公爵从高斯14岁开始资助他学习。高斯进了不伦瑞克工业大学，虽然不是什么了不起的大学，但毕竟开始正规念书了。[^fxA011]18岁转到哥廷根大学——这跟你们进清华是一样的，你们现在有能力学好的学问了。

高斯18岁（1796年3月30日）证明了正十七边形可以用尺规作图。[^fxA013]这表面上看起来不重要，但对他影响很大，因为他由此深入研究了分圆域（cyclotomic field）。他给了十多个不同的证明[^fn01008]，并在日记中写道：他发现很多图形如十七边形的作图可以实现，可能不过是某个更广泛理论的分支。他后来成为哥廷根大学教授兼天文台台长。

高斯17岁就发现了素数分布定律（prime number distribution law）和最小二乘法。素数分布——即 $\pi(x)$（小于 $x$ 的素数个数）[^s30345]——他通过大量计算（算到十的十次方，在没有计算机的年代极不容易）[^fxA017]发现 $\pi(x)$ 与 $\int dx/\log x$ 非常接近[^fxR2B2018]。这个猜想等了七八十年，直到1896年才由哈达玛（Hadamard）和德拉瓦莱-普桑（de la Vallée-Poussin）用黎曼 ζ 函数证明[^fn01009]，这是复变函数第一次被用于解决具体的数论问题[^s30342]。

最小二乘法由勒让德（Legendre）在1805年首次明确发表，但高斯说他1795年就知道了——后来发现的高斯日记证明他没有撒谎[^s30341]。高斯在此基础上创立了测量平差理论，用之计算天体运行轨道。1801年，意大利天文学家皮亚齐发现了一颗小行星（谷神星），追踪40天后在太阳强光下丢失了。高斯用最小二乘法从那40天的观测数据中算出了轨道，后来匈牙利天文学家据此重新找到了谷神星。高斯还将最小二乘法与正态分布（即高斯分布）联系起来——他从最小二乘法出发，发现算术平均值是未知参数的最优估计，这一要求唯一地导出正态分布。1810年，拉普拉斯证明了中心极限定理，为高斯正态分布奠定了严格基础。

1818年至1826年间，高斯在德国从事大地测量工作，由此对微分几何产生巨大兴趣。他最重要的贡献之一是开创性地用参数表示曲面[^fxR2B2012]——不像笛卡尔只用方程 $F=0$，而是用平面上的参数映射到曲面上。这一点至关重要，因为它使曲面概念得以推广到高维空间，直接影响了黎曼几何。与之相关的是共形映射（conformal mapping）的研究——在二维情形下，共形映射使拉普拉斯方程等形式变化不大[^fn01010]，对流体力学、电磁学等计算极有帮助。

高斯定义了曲面上每点的两个主曲率 $k_1$ 和 $k_2$，并提出了高斯曲率（Gaussian curvature）$K = k_1 \cdot k_2$。[^fxA001]他证明了一个划时代的结论：K 只依赖于曲面本身的度量，与曲面在三维空间中的嵌入方式无关。这一内蕴几何（intrinsic geometry）的观念直接催生了黎曼几何。高斯还定义了高斯映射（Gauss map）：将曲面上每点的法向量平移到原点，得到从曲面到单位球面 $S^2$ 的映射。高斯曲率可由此映射的雅可比行列式表示。而高斯曲率在曲面上的积分等于 $S^2$ 上相应区域的面积[^fn01011]，由此可简洁地推导出高斯-博内定理（Gauss-Bonnet theorem）：$\int K\,dA = 2\pi\chi$[^fn01012]——左手边是微分几何量，右手边是欧拉示性数，一个拓扑不变量。这是第一次将微分几何与拓扑学用桥梁连接起来，对20世纪数学影响深远。高斯映射的推广——将切平面映射到格拉斯曼流形（Grassmannian）——成为现代拓扑学中陈类（Chern class）理论的源头。

高斯还发现了环绕数（linking number）的积分公式：两条封闭曲线的环绕数可用一个二重积分表示，积分内的被积函数在曲线移动时剧烈变化，但积分结果保持不变且为整数——这与高斯-博内定理异曲同工，隐藏着深刻的守恒律。此公式直到近年才通过量子场论（Chern-Simons理论）得到较好的解释。

高斯也研究了欧氏几何的平行公理问题——困扰数学家两千年。他认识到平行公理不能用其他四条公理证明，并私下相信非欧几何的存在。他的朋友的儿子波尔约（Bolyai）在1823年证明了非欧几何的存在性[^fn01013]，高斯对他非常赞赏。同时期俄罗斯的罗巴切夫斯基（Lobachevsky）也独立得到了相同结论。

高斯是第一个比较严格地证明代数基本定理的人（1799年博士论文）[^fn01014]，即任何 n 次复系数多项式恰好有 n 个复根（计重数）。他给出多个证明，其中第一个考虑 $f(z)$ 的实部和虚部的零点曲线何时相交，本质上是一个拓扑学的问题。

在数论上，高斯19岁证明了二次互反律（quadratic reciprocity law）[^fxA018]，他称之为"最优雅的基本定理"[^s30347]，后来给了六个不同证明。这一结果深远影响了现代算术几何的发展。他还在椭圆函数方面做了大量工作——研究双周期函数、超几何级数（hypergeometric series），发现算术几何平均（arithmetic-geometric mean）与椭圆积分之间的深刻联系，并在17岁时就提出了模方程（modular equation）的概念[^fn01015]——通过算术几何平均算法，他演绎出模函数的基本性质，这在后来成为代数曲线研究的重要工具。

高斯在物理学上也贡献卓著：他与韦伯（Weber）制造了第一台可操作的电报；高斯定律是麦克斯韦方程组的第一方程，其数学形式依赖散度定理——散度定理的早期形式由拉格朗日给出（1762），高斯1813年证明了特殊情形，一般形式归功于奥斯特罗格拉茨基；高斯本人也将散度定理广泛应用于流体动力学和电磁学。[^fxR1B1024]

高斯的座右铭是："大自然，你是我的女神，我愿意在你的定律面前俯首听命。"他从贫寒家庭出身，14岁前生活艰苦，全靠自己奋斗。他一生有146个重要发现未曾发表[^fxA014]——因为他追求完美，只想留下"完美的艺术品"。他讲："一座大教堂，最后拆掉架子、撑柱和挪走后，才能算是一座大教堂。"他告诫我们要慢慢磨，不要急于发表不成熟的成果。他对数学充满兴奋感——十七边形他给了十多个不同的证明[^fxA016]，二次互反律他给了六个，因为觉得有意思。你们一定要培养自己对某个问题的兴奋感，有了这种感觉，才能做出好的数学。
