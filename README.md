编者：**Glorious Shards**

本书为清华大学求真书院数学史课程的精编稿，覆盖 42 讲。正文分三层：整理者概述、演讲原文、页下脚注。本书不是逐字实录；文字稿由机器转写，再经人工复核（回听、幻灯片与文献核对）。

## 内容

- `md/`：42 讲修订后的 Markdown 源文件，按学期分目录；
- `求真书院数学史.pdf`：成品电子版；
- `ERRATA.md`：已知问题与勘误；
- `.github/ISSUE_TEMPLATE/`：勘误报告模板。
